# Algedonia

This repository contains the Algedonia daemon (`ag`) and server components.

## Daemon

The daemon binary is `ag` (built from `daemon/cmd/algedonia-agent`).

Common commands:

- `ag login` to store connection settings
- `ag connect` to run the daemon
- `ag uninstall` to remove the daemon and its auto-start service

## Server

See `server/README.md` for Phoenix server setup.
